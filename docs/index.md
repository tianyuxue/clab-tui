# clab-tui documentation

**English** | [简体中文](zh-CN/index.md)

clab-tui is a terminal UI for [containerlab](https://containerlab.dev). It scans your
`.clab.yml` files and lets you browse topologies, run the lab lifecycle, open node
sessions, watch logs and stats, apply link impairments, and capture or trace traffic
— all from the keyboard.

## Who this is for

Network engineers and developers who run containerlab labs and prefer a
terminal-native workflow over a GUI.

## Prerequisites at a glance

- Linux
- [containerlab](https://containerlab.dev/install/) on `PATH` (not bundled)
- Docker with a running daemon
