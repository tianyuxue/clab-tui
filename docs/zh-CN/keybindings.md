# 快捷键

[English](../keybindings.md) | **简体中文**

clab-tui 完全由键盘驱动。按 `?` 展开帮助栏，或按 `space` 打开 which-key 菜单，其中会
列出当前标签页的所有可用操作。

## 全局

| 按键 | 操作 |
|-----|--------|
| `q` / `ctrl+c` | 退出（若图服务器正在运行则将其停止） |
| `tab` / `right` | 下一个标签页 |
| `shift+tab` / `left` | 上一个标签页 |
| `1`–`4` | 跳转到 拓扑 / 会话 / 节点日志 / Ops Log |
| `space` | 打开 which-key 菜单 |
| `?` | 切换展开的帮助栏 |
| `/` | 搜索（拓扑标签页） |
| `l` | Lab 操作（拓扑标签页） |
| `o` | 节点或接口操作（拓扑标签页） |

## 拓扑标签页

| 按键 | 操作 |
|-----|--------|
| `j` / `k` | 下移 / 上移 |
| `g` / `G` | 跳到顶部 / 底部 |
| `ctrl+f` / `ctrl+b` | 向下翻页 / 向上翻页 |
| `enter` | 展开或收起所选节点的连接 |
| `x` | 切换所有连接摘要 |
| `i` | 切换接口行 |
| `n` / `N` | 下一个 / 上一个搜索匹配项 |
| `t` | 开始 / 停止路径追踪 |
| `f` | 更改追踪过滤器 |
| `o` | 节点/接口操作 |
| `l` | Lab 操作 |

## Which-key 菜单（space）

该菜单是模态的：按高亮字母进行选择，用 `j`/`k` 移动，按 `Enter` 确认分组或操作，
按 `Esc`/`q` 返回。

- **拓扑 → Lab**：Switch Lab（切换 Lab）、Deploy（部署）、Destroy（销毁）、
  Redeploy（重新部署）、Edit YAML（编辑 YAML）、View Graph（查看图）。
- **拓扑 → 节点**：SSH、Start（启动）、Stop（停止）、Restart（重启）、Pause（暂停）、
  Unpause（恢复）、View Logs（查看日志）。
- **拓扑**：Trace（追踪）、Filter（过滤）、Search（搜索）。
- **会话**：Switch Session（切换会话）。
- **节点日志**：Follow（跟随）、Clear（清除）、Top（顶部）、Bottom（底部）。
- **Ops Log**：Follow（跟随）、Clear（清除）。

## 会话标签页

会话有两种模式。

**插入模式（默认）**——所有按键都会发送到活动 shell，包括 `ctrl+c` 和 `tab`。
按 `ctrl+\` 离开。

**普通模式**：

| 按键 | 操作 |
|-----|--------|
| `enter` 或 `space` | 返回插入模式 |
| `s` | 打开会话选择器 |
| 标签字母（`a`–`z`） | 切换到该会话 |
| `q` | 关闭活动会话 |
| `j` / `k` | 滚动视口 |
| `tab` / `shift+tab` | 下一个 / 上一个标签页 |
| `space` | 打开 which-key 菜单 |

## 节点日志标签页

| 按键 | 操作 |
|-----|--------|
| `f` | 切换跟随 |
| `c` | 清除 |
| `g` / `G` | 顶部 / 底部 |

## Ops Log 标签页

| 按键 | 操作 |
|-----|--------|
| `f` | 切换跟随 |
| `c` | 清除 |

## 抓包面板

抓包面板是拓扑标签页上的一个浮层，在抓包进行时显示。

| 按键 | 操作 |
|-----|--------|
| `q` | 关闭（停止抓包） |
| `c` | 清除 |
| `p` | 暂停 / 继续 |
| `w` | 将当前数据包保存为 pcap 文件 |

## 列表与表单

- **Lab 选择器 / 操作菜单 / 会话选择器**：`j`/`k` 移动，`enter`/`space` 选择，
  `[`/`]` 翻页，`esc`/`q` 关闭，按字母键跳转到某一项。
- **搜索输入框**：`enter` 确认，`esc` 取消；方向键和 `home`/`end` 用于编辑。
  同一个输入框也复用于自定义抓包过滤器和 pcap 保存路径。
- **Netem 表单**：`tab`/`down` 下一个字段，`shift+tab`/`up` 上一个字段，`enter`
  应用，`esc` 取消。字段：Delay（延迟）、Jitter（抖动）、Loss（丢包）、Rate（速率）、
  Corruption（损坏）。
