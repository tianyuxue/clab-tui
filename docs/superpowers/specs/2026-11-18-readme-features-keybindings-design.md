# README 功能与快捷键更新设计

## 意图

根据当前 clab-tui 的实际 UI 能力，更新根目录 `README.md` 和
`README.zh-CN.md`，让新用户能快速了解主要功能、四个标签页以及常用操作，
尤其是键盘快捷键和 Sessions 的模式切换。

## 范围

- 更新中英文 README 的 Features/功能特性，补充多标签页、which-key 菜单、
  拓扑导航、自动刷新和会话交互等当前能力。
- 更新中英文 README 的快捷键速查表，覆盖全局导航、拓扑常用操作、日志操作、
  抓包面板和会话模式的关键入口。
- 保留完整快捷键细节在 `docs/keybindings.md`，README 继续链接该文档。
- 不修改程序代码、完整快捷键文档或快捷键行为。

## 非目标

- 不新增截图、命令行参数或配置项文档。
- 不重写 `docs/keybindings.md` 的全部内容。
- 不改变任何快捷键或 UI 行为。

## 方案

1. 只更新根目录中英文 README：改动集中，直接满足 README 更新需求。
2. 同步重写 README 和完整快捷键文档：覆盖更全面，但范围和维护成本更大。
3. 只增加指向现有文档的链接：维护成本最低，但 README 仍不能独立说明核心操作。

采用方案 1，因为现有完整快捷键文档已经覆盖详细行为，本次重点是让 README 的
功能介绍和高频快捷键与当前实现保持一致。

## 实现约定

- 以 `internal/tui/model.go`、`internal/tui/keys.go`、`tabs/whichkey.go`、
  `tabs/sessions.go` 和现有 `docs/keybindings.md` 为事实来源。
- 中英文 README 保持章节结构和信息范围一致，分别使用自然的中文和英文表达。
- 仅在 README 中突出高频入口；复杂菜单项、列表/表单细节继续通过文档链接提供。

## 验证

- 检查两个 README 的功能与快捷键表是否对应当前实现和完整快捷键文档。
- 检查新增/保留的文档链接路径存在。
- 运行仓库已有的文档相关轻量检查；若没有专门检查，则使用 Markdown/路径脚本验证。
